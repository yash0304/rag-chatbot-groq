# Legacy: Conversational RAG Q&A Chatbot (Streamlit + Groq)

This folder preserves the original project this repository started as — a Streamlit
chatbot that answers questions about uploaded PDFs using LangChain, FAISS, HuggingFace
embeddings, and Groq. It is kept for reference and is no longer developed.

Run it the old way:

```bash
pip install -r requirements.txt
streamlit run groqRAGAppWithHistory.py
```

The repository's active project is **MindQuest** — see the [root README](../../README.md).
